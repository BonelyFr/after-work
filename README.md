# After the Work Day

A weekday after-work schedule app: day tabs, checklists, notes, add/remove tasks and workout plans.
It runs entirely in the browser. Checks, notes and added tasks are saved on the device you use it on.

## Put it on GitHub Pages

1. Sign in at github.com and click **New repository**. Name it, for example, `after-work`. Choose **Public** (free Pages needs a public repository) and create it.
2. On the new repository page click **uploading an existing file**. Drag in every file from this folder (`index.html`, `manifest.webmanifest`, `sw.js` and the three `icon-*.png` files), then click **Commit changes**.
3. Open **Settings**, then **Pages**. Under **Build and deployment** set **Source** to **Deploy from a branch**, pick **main** and **/ (root)**, then **Save**.
4. Wait a minute or two. The page shows your address, which looks like `https://YOUR-USERNAME.github.io/after-work/`.

## Install it on your iPhone

1. Open that address in **Safari**.
2. Tap **Share**, then **Add to Home Screen**, then **Add**.
3. Open it from the new icon. It runs full screen and works offline after the first visit.

## Good to know

- The repository is public, so anyone with the link can see the schedule and workout plan. Your checks and notes never leave your device.
- Use only the Home Screen icon after you add it. Safari and the Home Screen icon each keep their own saved checks and notes.
- To change something later, edit `index.html` on GitHub (pencil icon), commit, then reopen the app. If an old version shows, close the app fully and open it again.
